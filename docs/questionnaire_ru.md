# Опросник обратной связи: ARIZAgent (АРИЗ-85-В + ИИ)

Файл для переноса в **Google Forms** и для описания методики в статье ВАК (тематика: ИИ для образования, науки и бизнеса).

---

## 1. Назначение и научная рамка

| Параметр | Описание |
|----------|----------|
| Цель продукта | Собрать обратную связь для улучшения ARIZAgent |
| Цель исследования (опционально) | Оценить принятие инструмента на базе ИИ для поддержки решения изобретательских / инженерных задач в контекстах образования, науки и бизнеса |
| Дизайн | Одномоментный (cross-sectional) опрос после использования инструмента |
| Теоретическая основа | Адаптация **TAM** (Davis, 1989): воспринимаемая полезность (PU), воспринимаемая лёгкость использования (PEOU), поведенческое намерение (BI); дополнения: **доверие к ИИ**, **воспринимаемое качество результата**, **когнитивная / учебная ценность**, элементы **UTAUT** (облегчающие условия); краткий блок сопоставим с логикой **SUS** |
| Шкала Лайкерта | **1–5**: 1 — совершенно не согласен; 2 — скорее не согласен; 3 — затрудняюсь ответить; 4 — скорее согласен; 5 — совершенно согласен |
| Язык | Русский |
| Время заполнения | 8–12 минут |
| Критерий включения | Респондент **хотя бы один раз** получил итоговый отчёт / ответ от ARIZAgent по своей или учебной задаче |
| Анонимность | По умолчанию без ФИО и email (email — только добровольно в конце) |

### Рекомендуемые гипотезы (для статьи)

- **H1.** Воспринимаемая полезность (PU) положительно связана с намерением использовать ARIZAgent (BI).  
- **H2.** Воспринимаемая лёгкость использования (PEOU) положительно связана с PU и с BI.  
- **H3.** Доверие к результатам ИИ (TR) и воспринимаемое качество результата (PQ) положительно связаны с BI.  
- **H4.** Оценка учебной / метакогнитивной ценности (LV) выше у респондентов из контекста образования (сравнение групп).  
- **H5.** Респонденты оценивают структурированный АРИЗ-проход выше, чем «один запрос к обычному чат-боту» (блок сравнения).  

### Обработка (кратко для «Методы»)

1. Кодирование пунктов 1–5; для reverse-пунктов — инверсия: `6 − x`.  
2. Балл конструкта = среднее арифметическое входящих пунктов.  
3. Надёжность: коэффициент α Кронбаха по каждому конструкту (ориентир α ≥ 0,7).  
4. Описательная статистика (M, SD), корреляции Спирмена/Пирсона, при N достаточно — регрессия BI ~ PU + PEOU + TR + PQ; сравнение групп (образование / наука / бизнес) — Краскал–Уоллис или ANOVA.  
5. Открытые ответы — тематический анализ.  
6. В Google Forms: включить сбор только от прошедших скрининг S1 = «Да».

### Этика и согласие

В начале формы — текст согласия. Персональные данные минимальны. Для ВАК указать: добровольность, возможность прервать опрос, использование обезличенных данных в научной публикации и для доработки ПО.

## 2. Как перенести в Google Forms (пошагово)

1. Создайте форму → название: **«Обратная связь: ARIZAgent (АРИЗ + ИИ)»**.  
2. Включите **«Только один ответ»** при необходимости; для исследования часто оставляют без входа Google.  
3. Создайте **разделы** (Sections) точно как блоки A→H ниже.  
4. Для каждого вопроса смотрите колонку **Тип в Google Forms**.  
5. Для всех Лайкерт-вопросов:  
   - тип **Линейная шкала** (Linear scale), от **1** до **5**;  
   - подписи: слева «Совершенно не согласен», справа «Совершенно согласен».  
6. Обязательные: согласие, скрининг S1, все Лайкерт-пункты конструктов, внимание ATT1.  
7. В конце: «Ссылка на результаты» выкл.; добавить вашу политику/контакт по желанию.  
8. Экспорт ответов → Sheets → столбцы с кодами `CONSENT`, `S1`, `D1`, `PU1`… как в таблице.

**Единый набор подписей шкалы (скопировать):**  
`1 — Совершенно не согласен` · `2 — Скорее не согласен` · `3 — Затрудняюсь ответить` · `4 — Скорее согласен` · `5 — Совершенно согласен`

### РАЗДЕЛ D. Шкалы TAM и смежные конструкты

**Описание раздела:**  
Оцените утверждения по шкале от 1 до 5, где 1 — «совершенно не согласен», 5 — «совершенно согласен».

#### D.1. Воспринимаемая полезность — PU (коды `PU1`–`PU4`)

| Код | Тип | Текст утверждения | R |
|-----|-----|-------------------|---|
| PU1 | Линейная шкала 1–5 | Использование ARIZAgent помогает мне быстрее разобрать техническую / изобретательскую задачу | |
| PU2 | Линейная шкала 1–5 | ARIZAgent повышает качество моей постановки задачи и поиска направлений решения | |
| PU3 | Линейная шкала 1–5 | Результаты работы с ARIZAgent полезны для учёбы, исследования или работы | |
| PU4 | Линейная шкала 1–5 | В целом я считаю ARIZAgent полезным инструментом | |

#### D.2. Воспринимаемая лёгкость использования — PEOU (`PEOU1`–`PEOU4`)

| Код | Тип | Текст | R |
|-----|-----|-------|---|
| PEOU1 | 1–5 | Мне было легко разобраться, как пользоваться ARIZAgent | |
| PEOU2 | 1–5 | Взаимодействие с инструментом (чат, получение отчёта) понятно | |
| PEOU3 | 1–5 | Чтобы пользоваться ARIZAgent, мне не потребовалось много усилий на обучение | |
| PEOU4 | 1–5 | **Мне было трудно** настроить или запустить ARIZAgent | **rev** |

> `PEOU4` — обратный пункт: при подсчёте `PEOU4_r = 6 − PEOU4`.

#### D.3. Доверие к ИИ-результатам — TR (`TR1`–`TR3`)

| Код | Тип | Текст | R |
|-----|-----|-------|---|
| TR1 | 1–5 | Я в целом доверяю формулировкам и выводам, которые предлагает ARIZAgent | |
| TR2 | 1–5 | Я считаю нужным **критически проверять** ответы ARIZAgent перед использованием | |
| TR3 | 1–5 | Даже если отдельные шаги спорны, структуре разбора по АРИЗ можно доверять как опоре для мышления | |

> TR2 не обязательно инвертировать: он измеряет **критическую установку** (желательную). В статье можно анализировать отдельно как «critical trust» или оставить описательно. Для индекса «наивного доверия» используйте TR1+TR3; TR2 — отдельный индикатор.

#### D.4. Воспринимаемое качество результата — PQ (`PQ1`–`PQ4`)

| Код | Тип | Текст | R |
|-----|-----|-------|---|
| PQ1 | 1–5 | Итоговый отчёт был структурированным и понятным | |
